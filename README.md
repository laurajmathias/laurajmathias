# Olá, eu sou a Laura 👋

Estudante de **Desenvolvimento de Software Multiplataforma** na **FATEC Registro**, cursando o 2º semestre.

Entrei na tecnologia pelo **design e pelo UX/UI** e hoje estou migrando para o **desenvolvimento**, construindo minha stack com foco em back-end. Gosto de juntar os dois lados: código que funciona e que também é pensado para quem vai usar.

## O que estou construindo

**[Lia Messages API](https://github.com/laurajmathias/Lia-Messages-API)**: API de mensagens (CRUD) para uma assistente de vendas no WhatsApp, feita para um teste técnico.

- Node.js, TypeScript e Express, com MySQL no Docker e Prisma
- Validação de toda entrada com Zod e erros em formato único
- 20 testes de integração contra um banco real, separado do de desenvolvimento
- README validado clonando o repositório do zero
